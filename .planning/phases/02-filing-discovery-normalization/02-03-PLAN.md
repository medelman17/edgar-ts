Create `src/discovery/service.ts` with DiscoveryService class:

**Class signature:**
```typescript
export class DiscoveryService {
  constructor(private readonly httpClient: SecHttpClient) {}

  async discoverFilings(input: DiscoverFilingsInput): Promise<FilingRef[]>
}
```

**Implementation flow for discoverFilings():**

1. **Input validation**:
   - validateDate(input.from) — throw ValidationError if invalid
   - validateDate(input.to) — throw ValidationError if invalid
   - Verify from <= to — throw ValidationError if reversed
   - If input.cik provided: normalize via normalizeCik() (store as normalizedCik)
   - If input.formTypes not provided: default to ["8-K", "10-K", "10-Q", "20-F", "S-1", "8-K/A", "10-K/A", "10-Q/A", "20-F/A", "S-1/A"]
     - Note: includes common amendment variants per research guidance
   - Normalize all form types in filter array via normalizeFormType()

2. **Fetch filings**:
   - If CIK provided: call fetchAllFilings(normalizedCik, this.httpClient)
   - If NO CIK: throw NotImplementedError with message "Discovery without CIK requires Daily Index Files (planned for future release)"
     - Rationale: Phase 2 scope limited to Submissions API (CIK-scoped); Daily Index integration deferred

3. **Filter by date range**:
   - Filter fetched filings: keep only where filingDate >= input.from AND filingDate <= input.to
   - Use string comparison (ISO 8601 dates are lexicographically comparable)

4. **Filter by form types**:
   - Normalize each filing's form field via normalizeFormType()
   - Keep only filings where normalized form is in normalized formTypes array

5. **Normalize filings**:
   - Map each filtered filing to FilingRef:
     - cik: normalizeCik(filing.cik) — SEC response may have unpadded CIK
     - accessionNo: normalizeAccession(filing.accessionNumber)
     - formType: normalizeFormType(filing.form)
     - filingDate: filing.filingDate (already YYYY-MM-DD)
     - filingUrl: buildFilingUrl(normalizedCik, normalizedAccession)

6. **Build filing URL helper**:
   - URL format: `https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK={cik}&type=&dateb=&owner=exclude&count=100&search_text={accessionNo}`
   - Alternatively (simpler): `https://www.sec.gov/cgi-bin/viewer?action=view&cik={cik}&accession_number={accessionNoCompact}&xbrl_type=v`
   - Use research recommendation: `https://www.sec.gov/cgi-bin/viewer?action=view&cik={cik}&accession_number={accessionNoCompact}&xbrl_type=v`
   - accessionNoCompact = accession with hyphens removed

7. **Deduplicate and sort**:
   - Call dedupeAndSort(normalizedFilings)
   - Return result
