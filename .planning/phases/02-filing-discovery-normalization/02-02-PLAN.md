  <action>
Create `src/discovery/pagination.ts` with recursive pagination logic:

1. **fetchAllFilings(cik: string, httpClient: SecHttpClient): Promise<FilingRecord[]>**

   Implementation flow:

   a. **Normalize CIK** (import from normalization.ts)

   b. **Fetch primary submission**:
      - URL: `https://data.sec.gov/submissions/CIK${normalizedCik}.json`
      - Use httpClient.request() (NOT raw fetch — must route through rate limiter)
      - Parse response as SubmissionsResponse type

   c. **Collect recent filings**:
      - Extract json.filings.recent array (first 1000 or fewer)
      - Initialize accumulator: allFilings = [...recent]

   d. **Iterate paginated files**:
      - For each file in json.filings.files array:
        - Construct full URL (IMPORTANT: use www.sec.gov, not data.sec.gov per research)
        - URL format: `https://www.sec.gov/${file.name}`
        - Fetch paginated file via httpClient.request()
        - Parse response (contains same FilingRecord[] structure)
        - Append to accumulator

   e. **Return complete array**

   Error handling:
   - HTTP errors bubble up from SecHttpClient (already typed)
   - JSON parse errors → throw ParseError from @/errors
   - Missing filings.recent or filings.files → default to empty array (SEC may return sparse data)

   Type annotations:
   - Explicit return type: Promise<FilingRecord[]>
   - Use SubmissionsResponse from ./types
   - No `any` types

Write tests in `tests/discovery/pagination.test.ts`:

Mock SecHttpClient using Vitest vi.fn(). DO NOT make real HTTP requests.

Test cases:
1. **Small CIK (no pagination)**: Mock response with 10 filings in recent, empty files array → verify 10 returned
2. **Large CIK (with pagination)**: Mock response with 1000 in recent, 2 paginated files → verify 1000 + (file1 count) + (file2 count) returned
3. **Empty recent array**: Mock response with empty recent, no files → verify empty array returned
4. **Pagination URL construction**: Verify paginated files use https://www.sec.gov/ base (NOT data.sec.gov)
5. **HTTP error propagation**: Mock httpClient throwing TransportError → verify error bubbles up
6. **Invalid JSON response**: Mock invalid JSON → verify ParseError thrown

Export from src/discovery/index.ts.
