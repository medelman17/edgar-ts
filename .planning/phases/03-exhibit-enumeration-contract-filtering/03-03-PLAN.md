Create `src/exhibits/service.ts` following Phase 2 DiscoveryService pattern:

**Class: ExhibitService**

Constructor:
```typescript
constructor(private readonly httpClient: SecHttpClient) {}
```

**Method 1: buildFilingIndexUrl(cik: string, accessionNo: string): string**
- Private helper method
- URL pattern: `https://www.sec.gov/Archives/edgar/data/{cik}/{accessionCompact}/index.html`
- Remove hyphens from accessionNo to get accessionCompact: accessionNo.replace(/-/g, "")
- CIK should already be normalized (10-digit zero-padded) from Phase 2
- Return complete URL string

**Method 2: buildExhibitUrl(cik: string, accessionNo: string, filename: string): string**
- Private helper method
- URL pattern: `https://www.sec.gov/Archives/edgar/data/{cik}/{accessionCompact}/{filename}`
- Same accessionCompact logic as buildFilingIndexUrl
- Return complete URL string

**Method 3: async listExhibits(filing: FilingRef): Promise<ExhibitRef[]>**
- Public method
- Orchestration flow:
  1. Build filing index URL using buildFilingIndexUrl(filing.cik, filing.accessionNo)
  2. Fetch index HTML: `const response = await this.httpClient.request(indexUrl)`
  3. Get HTML content: `const htmlContent = await response.text()`
  4. Parse exhibits: `const rawExhibits = parseExhibitTableFromHtml(htmlContent)`
  5. Normalize and build ExhibitRef objects:
     ```typescript
     const normalized = rawExhibits.map(raw => ({
       accessionNo: filing.accessionNo, // reuse from filing
       sequence: normalizeSequence(raw.sequence),
       type: normalizeExhibitType(raw.type),
       description: normalizeDescription(raw.description),
       filename: raw.filename,
       exhibitUrl: buildExhibitUrl(filing.cik, filing.accessionNo, raw.filename)
     }))
     ```
  6. Dedupe and sort: `return dedupeAndSortExhibits(normalized)`
- Import all normalization functions, parseExhibitTableFromHtml, dedupeAndSortExhibits
- Import FilingRef, ExhibitRef from @/types
- Add JSDoc explaining orchestration flow and dependencies

**Method 4: async listContractExhibits(filing: FilingRef): Promise<ExhibitRef[]>**
- Public method
- Orchestration flow:
  1. Get all exhibits: `const allExhibits = await this.listExhibits(filing)`
  2. Filter contracts: `return allExhibits.filter(e => isContractExhibit(e.type))`
- Import isContractExhibit from filters/contract
- Add JSDoc: "Lists only material contract exhibits (EX-10*) for a filing."

Explicit return types on all methods (isolatedDeclarations requirement).
