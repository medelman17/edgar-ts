**Implement dedupeAndSortExhibits(exhibits: ExhibitRef[]): ExhibitRef[]**

Deduplication strategy:
- Identity key: `${exhibit.accessionNo}:${exhibit.sequence}` (filing-local uniqueness)
- Use Map<string, ExhibitRef> to track first occurrence
- Retain first occurrence when duplicates found (matches Phase 2 behavior)

Stable sort strategy (two-level):
1. Primary: sequence NUMERIC ascending (parse to Number for comparison)
   - CRITICAL: "10" must come after "2" → use Number(a.sequence) - Number(b.sequence)
   - String comparison breaks multi-digit sequences (lexicographic: "2" > "10")
2. Secondary: filename STRING ascending (use localeCompare)

Algorithm:
```typescript
export function dedupeAndSortExhibits(exhibits: ExhibitRef[]): ExhibitRef[] {
  const identityMap = new Map<string, ExhibitRef>()

  for (const exhibit of exhibits) {
    const identity = `${exhibit.accessionNo}:${exhibit.sequence}`
    if (!identityMap.has(identity)) {
      identityMap.set(identity, exhibit)
    }
  }

  const deduplicated = Array.from(identityMap.values())

  return deduplicated.sort((a, b) => {
    // Primary: sequence (numeric)
    const seqA = Number(a.sequence)
    const seqB = Number(b.sequence)
    if (seqA !== seqB) return seqA - seqB

    // Secondary: filename (string)
    return a.filename.localeCompare(b.filename)
  })
}
```

- Explicit return type: ExhibitRef[]
- Import ExhibitRef from @/types
- Add comprehensive JSDoc explaining identity key and sort order
- NOTE: Function assumes inputs are already normalized (like Phase 2 dedupeAndSort)

Implementation:
```typescript
/**
 * Determines if a normalized exhibit type is a material contract (EX-10*).
 *
 * Matches all EX-10 variants including:
 * - Base: EX-10
 * - Dotted: EX-10.1, EX-10.2, EX-10.01
 * - Lettered: EX-10A, EX-10B
 *
 * @param normalizedType - Normalized exhibit type (uppercase, hyphenated)
 * @returns true if exhibit is a material contract, false otherwise
 *
 * @example
 * isContractExhibit("EX-10")     // true
 * isContractExhibit("EX-10.1")   // true
 * isContractExhibit("EX-10A")    // true
 * isContractExhibit("EX-21")     // false
 */
export function isContractExhibit(normalizedType: string): boolean {
  return /^EX-10(\.\d+|[A-Z])?$/.test(normalizedType)
}
```

- Explicit return type: boolean

- Single responsibility: pattern matching only (no normalization)
