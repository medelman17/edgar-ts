- Constructor accepts SecHttpClient: `constructor(private readonly httpClient: SecHttpClient) {}`
- Public method: `async downloadExhibit(exhibit: ExhibitRef): Promise<DownloadedExhibit>`

DownloadService.downloadExhibit() orchestration flow:
1. Fetch exhibit URL via SecHttpClient: `const response = (await this.httpClient.request(exhibit.exhibitUrl)) as unknown as { arrayBuffer(): Promise<ArrayBuffer>, headers: { get(name: string): string | null } }`
   - Cast to unknown then assume arrayBuffer() method (mirrors Phase 3 text() pattern and Phase 2 json() pattern)
   - Include headers in cast for Content-Type extraction

2. Extract optional MIME type from Content-Type header (may be undefined):
   - `const contentType = response.headers.get("Content-Type")`
   - Strip charset: `const mimeType = contentType?.split(";")[0]?.trim() ?? undefined`

3. Read binary response and convert to Uint8Array:
   - `const buffer = await response.arrayBuffer()`
   - `const bytes = new Uint8Array(buffer)`

4. Compute SHA-256 digest:
   - `const sha256 = await computeSha256Hex(bytes)`

5. Return DownloadedExhibit:
   - `return { exhibit, bytes, sizeBytes: bytes.length, mimeType, sha256 }`
   - Always use `bytes.length` for size (don't trust Content-Length header)

Import computeSha256Hex from ./hasher. Add JSDoc describing the flow.
